Runtime Characters
==================

Zweck
-----

Hier landen neue oder veraenderte Figuren zuerst als Arbeitsstand.

- Geeignet fuer neue NPCs, Umbenennungen, Rollenwechsel und offene Profilfelder.
- Nicht fuer stillschweigende Kanon-Promotion.

Dateikontrakt
-------------

- Eine Datei pro Figur: `characters/<slug>.md`
- Status klar markieren: `Probe`, `Arbeitsstand`, `review_required` oder `promotion_ready`
- Beziehungen, Inventare und Weltstatus nur verlinken, nicht hier doppelt ausfuehren
